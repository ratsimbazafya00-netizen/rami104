AJOUT CHAT — RAMI 104

- Chat disponible dans le lobby, pendant la partie et sur l'écran de fin.
- Messages conservés dans l'état persistant du salon, jusqu'à l'expiration/suppression du salon.
- Maximum 150 messages conservés par salon.
- Maximum 300 caractères par message.
- Le chat est indépendant du journal de manche : préparer une nouvelle manche n'efface pas le chat.
- Authentification obligatoire et vérification du joueur dans le salon côté serveur.
